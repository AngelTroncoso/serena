# serena

A Next.js application powered by Google Generative AI, built with TypeScript and Tailwind CSS.

## Getting Started

### Prerequisites

- Node.js 18+
- A Google Generative AI API key

### Installation

```bash
cd serena-app
npm install
```

### Environment Variables

Copy the example env file and fill in your values:

```bash
cp serena-app/.env.example serena-app/.env.local
```

### Development

```bash
cd serena-app
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

```bash
cd serena-app
npm run build
```
